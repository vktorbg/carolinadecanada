# Claude Code Project

This document contains information about the project and its interaction with Claude Code.

## Project Overview

This is a Next.js project for carolinadecanada with internationalization support (i18n) for English and Spanish.

## Recent Changes

- Added i18n support with English and Spanish translations
- Implemented the About page
- Added new home page components for showcasing categories and featured recipes
- Removed dotenv configuration
- Implemented conditional Contentful schema types to prevent build errors

## Tech Stack

- Next.js
- Contentful (conditionally configured)
- i18n (English and Spanish)
